# 🤖 RAG-Based Document QA Service

A Full-Stack Web Application that allows users to upload PDF documents and ask questions about them using an AI RAG (Retrieval-Augmented Generation) pipeline.

---

## 🛠 Tech Stack
- **Frontend**: React.js
- **Backend (Java)**: Spring Boot, Spring Data JPA, Spring Security (JWT)
- **Backend (AI)**: FastAPI, Python, OpenAI API
- **Database**: MySQL, Vector Database
- **Infrastructure**: AWS S3 (File Storage)
